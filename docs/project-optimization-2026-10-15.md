# 專案優化紀錄（2026-10-15）

本次檢查涵蓋專案檔案盤點、容器解析、功能分派、檔頭識別、文件及 MCP 產檔流程；不宣稱所有指令已完整支援。版本維持0.11.0，未打包。

## 實際修改

1. 新增 profiles.py，集中13種樣本檔頭、HeaderProfile與反向識別。移除service重複分支，保留原匯入介面與schema。只接受完全一致的已知檔頭。
2. process_functions.py 統一六個 operand 家族的編碼／解碼分派，使用bytes opcode索引，加入重複action／opcode及metadata完整性檢查。
3. ldr.py 移除逐網路複製、雜湊剩餘檔案的操作；保留CRC、截斷錯誤、未知tail及原樣重建。
4. 補上大量網路後截斷marker、未知metadata、所有profile辨識測試及維護文件。

- 重構後全套1354項既有測試通過；新增4項檢查後，test_ldr.py共48項通過。新增測試後未再次重跑整套。
