# 未發版變更

目前版本維持0.11.0；[0.11.0版本紀錄](release-0.11.0.md)之後新增下列內容，未製作安裝包。最後安裝包仍為0.10.0。

## 2026-10-13：test20

- 新增94P ASCWR MD=1、95 RAMP、98 RAMP2、100 R→T樣本形式的編解碼、狀態腳位與三路輸入。
- 完整Pt／WR／D+1／Tn及表格跨度檢查；RAMP2 OR暫存器僅在本指令內擴充。
- 手冊MD=1保留用途與ASCII來源長度明列未知；區分RAMP 10 ms、RAMP2 ms。
- 原樣本R15～R17工作區衝突，MCP拒絕整份生成；分開提供原N000～N002及N003試檔，不改使用者位址。
- 版本維持0.11.0，未打包；[支援形式與驗證](test20-functions.md)。

## 2026-10-12：test19

- 新增FUN86 TPCTL、87／88／89積算型計時的讀取與參數化編碼；67 CALL僅解析精確記錄。
- 新增FBe-20MA樣本檔頭、TIM／EN雙輸入、狀態腳位、完整暫存器／Y範圍與WR衝突檢查。
- 原始7個網路可解碼並逐位元組核對。依使用者澄清允許function所需M→M，保留無意義複製與helpers限制；目前全檔只因未解碼CALL目標拒絕生成，另提供保持原參數的N001～N006試檔。
- 計時器CV依7-81支援IR；TPCTL依7-79採32區與D4095範圍，記錄舊CH20差異。
- 版本維持0.11.0，未製作安裝包；驗證範圍見[test19文件](test19-functions.md)。

## 2026-10-12：test18

- 新增 FUN32 ADCNV、34 MLC、40 BITRD、41 BITWR 的樣本形式及參數化編碼。
- 保留65 LBL／66 JMP精確樣本配對；跳躍目標欄位尚未解碼，因此只允許完整原樣重建，不推定任意搬動後仍有效。
- 支援第二路輸入、狀態輸出、動態表格長度的最大可能跨度，並整合I/O與三層 M→M 政策檢查。
- MCP stdio 原樣產檔400 bytes相同，另附不含跳躍的資料處理試檔。701項測試通過；沒有新指令執行模型、GUI或PLC驗證。

形式、手冊頁碼與限制見 [test18文件](test18-functions.md)。

## test21

加入 FUN101～104 的16-bit非P、直接R/D與常數L編碼；保留EN／INC／CLR與END／ERR。修正先前test20 CLR一律反相的推論，原始bytes不變。新增FBe-40MC精確檔頭、完整表格資源範圍、測試及文件；不升版、不打包。詳見[test21](test21-functions.md)。

## test22（2026-10-14）

加入FUN105～112樣本形式、FB-28MA精確檔頭、完整表格資源及BKCMP連續輸出檢查。QUEUE／STACK指標語意與M1975記錄於手冊參照。不升版、不打包；詳見[test22](test22-functions.md)。

## test23（2026-10-14）

加入FUN120～127、HB1-32M精確檔頭及四路控制編解碼。MINV支援暫存器L並保守追蹤256-word範圍；其他樣本矩陣指令支援常數L，指標以bit計。維持版本、不打包，詳見[test23](test23-functions.md)。

## test24（2026-10-14）

加入 FUN08／09／10、113／114、128～130 的樣本形式、逐腳位控制與狀態編解碼。Z-WR N直接編碼，MBCNT只寫單word，WY8追蹤Y8～Y23全部輸出，TOGG追蹤目的讀寫。版本維持0.11.0，未打包；詳見[test24](test24-functions.md)。

## test25（2026-10-14）

新增FUN42～49樣本編碼與參數化支援，區分部分目的保留、UNIT／DIST補零及BUNIT暫存器N。靜態分析納入雙端交換、最大動態跨度及完整word I/O契約。未升版、未打包；見[test25](test25-functions.md)。
