# v0.3：使用者說需求，agent 交付 .ldr

主流程已改成「由 host agent 理解自然語言 → 呼叫 generate_ldr → 回傳實際檔案」。
MCP 不內建另一個語言模型、不需要 API key，也不是以關鍵字匹配假裝理解任意中文；
自然語言的理解由連接它的 agent 負責，MCP 提供設計指南、編譯、檢查、模擬與檔案輸出。
使用者不需手寫 JSON，也不需為支援範圍內的新參數提供 binary sample。

## Agent 操作

1. `get_design_guide` 取得流程、完整範例及 IR schema。
2. 將需求整理成 condition 字串與 block 參數。說明 Start/Stop 的輸入極性、
   自保持與同時按鈕的優先順序，不把範例的參數當成使用者已指定的條件。
3. 布林電路使用 simulate_ladder 檢查啟動、保持、停止及互鎖；Timer/Counter 時序不由布林模擬驗證。
4. 呼叫 `generate_ldr(output_name, ladder)`。推導編碼預設開啟，不需要 allow_unverified 旗標。
5. 回傳輸出檔案連結、design_summary 和 validation 狀態。

舊的 create_ldr/modify_network 保留原有明確旗標，供需要較嚴格流程的 client 使用。
一般使用者優先走 generate_ldr；不要因「尚未匯入」就拒絕生成支援的候選程式。

## condition 語法

```text
(X0 OR Y0) AND NOT X1
Y2 AND (X4 OR X5 OR (X6 AND NOT X7))
NOT (X0 OR X1) AND M240
```

支援 AND/OR/NOT、&/|/!、括號、TRUE/FALSE；AND 優先於 OR。
X/Y/M/T/C 的本版軟體位址範圍為 0..255。這是推導編碼範圍，並非各 PLC 的實體容量保證。
legacy steps 保留左摺疊順序。condition 和 steps 不可同時使用。
普通/反相 Y/M coil 支援 `inverted` 欄位。
條件長度上限 4096 字元、AST 256 nodes、深度 32；只解析允許的語法，不使用 eval。

## Timer/Counter 已從白名單改為參數化推導

Timer：time_base 固定 `0.01s`，address 0..255，preset 0..65535，enable 可填 Boolean expression。
例如持續 X0 三秒後動作：

```json
{"networks": [{"block": {"type": "timer", "address": 0, "preset": 300, "enable": "X0"}, "coils": [{"address": 0}]}]}
```

Counter：address 0..255、preset 0..65535，pulse/clear 可填 expression；coils 可省略或接 Y/M。
例如 X0 計數十次、X1 清除：

```json
{"networks": [{"block": {"type": "counter", "address": 0, "preset": 10, "pulse": "X0", "clear": "X1"}, "coils": [{"address": 0}]}]}
```

以上輸入接點、未觀測參數及 Counter 輸出連接屬推導，不是假稱已完成匯入或 PLC 時序驗證。
allow_unverified=false 的舊 create_ldr 仍會擋住這類新組合；新 generate_ldr 會生成並帶 warning。

## 推導依據

| 規則 | 樣本支持與限制 |
| --- | --- |
| device bit address：X=0x000+n、Y=0x100+n、T=0x200+n、C=0x300+n、M=0x810+n | 已觀測低位址相符；跨頁及較高位址為外推 |
| 指令群 0x40 load、0x60 子分支、0x80 AND、0xA0 OR；NC 加0x10 | 低 nibble 放 device address 高位；既有 NO/NC 樣本相符，未出現的 device/位置組合為推導 |
| E2 00 合併 AND、E4 43 合併 OR | test N005 與 test4 N007 的括號結構重建出完全相同 bytes；通用性為推導 |
| C0/D0 群普通/反相 coil | 普通 Y/M 多例、反相 Y2 一例；反相 M 為外推 |
| Timer：enable + FD80 + preset BE16 + (0x390+2n) BE16 | 所有既有 Timer bytes 一致；其他位址/參數/enable expression 為外推 |
| Counter：pulse + nested NOT(clear) + F940 + preset BE16 + (0x590+2n) BE16 | 重建既有 C1/C2/C3 bytes；輸入變化及通用性尚未匯入驗證 |
| block 後接 coil：6F FC + coil bytes | Timer 兩例支持；Counter 後接 coil 為推導 |

推導狀態不因本機測試通過就變成 WinProLadder 官方規格。

## 測試與剩餘限制

104 個測試通過。150 個隨機 Boolean trees × 16 種輸入，以独立測試 VM 驗證 2400 組結果。
所有 35 筆原始 record 保持結構 round-trip；其中 33 筆可語意解碼並重建原 payload。
剩餘兩筆 rising/falling edge contact 仍 opaque，不把它們猜成普通接點。
實際 MCP client 可探索 13 個工具並自動生成檔案。

尚未實作 SET/RST、MOV/比較/算術/暫存器 function blocks、其他 Timer time base、PLC 通訊。
本版產生新控制程式的能力已有擴充，但不宣稱涵蓋任意 PLC 指令或等同 WinProLadder syntax check。
