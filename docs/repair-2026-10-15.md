# 2026-10-15 MCP 修復與驗證

[文件索引](README.md) · [功能清單](../FEATURES.md)

本次修改維持 0.11.0，不打包、不改工作區政策。工作區原有 test28～30 及文件修改保留。

## 已完成的程式修復

- 11 種控制配方的標準配置通過嚴格政策；微分用 DIFU/DIFD，toggle 用 TOGG，off-delay/pulse/star-delta 的狀態用 R。啟停與正反轉保留既有 Y 自保持語意。
- 1～16 步 sequence 使用 R 狀態及無條件 ZNCMP 結果，轉移讀取同一掃描的階段快照，避免零時步驟連續跳過。reset 優先 abort，完成優先同時逾時。
- 原生 pause 使用 FUN87：TIM 暫停、EN 清除；不增加外部 X clock。一般無 pause 流程仍使用普通 T。
- ControlSpec/SystemSpec 增加 register_base，分配及檢查完整 2-word 範圍；SequenceSpec 可指定 register_base，保留狀態、零值與計時 CV/PV 範圍。
- 嚴格政策禁止所有自動產生的 relay helpers，包括 X-only helpers；來源、lowered、bytes 的既有 M→M 檢查保留。create/generate/edit 與 validate 預覽一致。
- 新增有界 runtime：直接 R/D 的加減乘除、加減一、AND/OR/XOR/XNR、CMP/ZNCMP、MOV/MOV反相、BCD；DIFU/DIFD、TOGG、普通 T/C、FUN87～89。未列入的 action 明確拒絕，不假裝模擬。
- acceptance 與 simulate_ladder 可接收嚴格 bool/int。算術驗收同時針對設計與實際 bytes 解碼結果；故意破壞編碼的回歸測試會拒絕產檔。
- get_capabilities 新增逐 action instruction_matrix，分別揭露編碼、生成、模型、GUI 與 PLC 證據，不把 FUNC 名稱當成全部形式皆支援。

## 模型假設與手冊

- 基本應用指令 7-18～19：DIFU/DIFD；7-25：TOGG；7-26～34：算術、遞增遞減與比較。
- 進階篇應用指令 7-27：ZNCMP；7-81～82：積算計時 TIM/EN、單位與 CV/PV。
- words 用 unsigned 16-bit 儲存，signed 運算轉換 bit15；負數 initial/expected 正規化為其 16-bit 表示。MUL/DIV 保留兩個輸出 word，負數除法朝零取商。
- 比較在 EN=false 時保留旗號，採 M1919=0 假設；不宣稱涵蓋其他 PLC 規劃。高階狀態比較一律無條件執行。
- scan_ms 為確定性掃描邊界模型；普通 T 採 T0～49 的 .01s 規劃。積算計時暫停保留模型內的小於一個 tick 的餘數，不代表已量測實體時脈相位。CV/PV 模型限 0～32767、直接 R/D。
- 缺少的 words/bit 初始值為零／false；正式工程必須確認啟動狀態，或先使用需求指定的 reset。沒有斷電保留保證。

## 回歸驗證

新增測試包含：11 配方嚴格政策產檔與解碼重播、數值溢位與負數商餘數、unsigned/signed 比較、暫停的小數 tick、重置優先、16 階段不連跳、暫存器衝突及編碼故障注入。

顯示槽測試以明確的測試 I/O 驗收 9.9、0.0、9.8：秒位先、十分位後，每個 50 ms 槽有 40 ms ON／10 ms OFF。驗收實際輸出 bytes 解碼程式，並非只驗證一個獨立 Python 計算。此 fixture 不等於指定客戶 I/O 的完整倒數應用。

真實 stdio 驗證涵蓋 17 個情境（11 配方、多控制、外部時脈 sequence、普通 T sequence、原生 pause、連接布林、T/C），檢查 CRC、SHA-256、資源下載、解碼行為及失敗不產檔。本機 manifest 位於 artifacts/release-20261015T133100Z-f08ce625/manifest.json。

## 尚需額外證據的項目

這些項目不能因離線測試通過而標成完成：

| 項目 | 精確限制／所需證據 |
| --- | --- |
| JMP/CALL 重定位 | 進階 7-60～61 說明 PLC 語意，但未說明 LDR target metadata；需要同一完整 LBL/JMP/CALL/RTS 程式逐項變動的 GUI exports。既有保護不放寬。 |
| 其他 D/P／間接／常數形式 | 依功能表逐項列出的 codec 限制；不能從單一 opcode 推算所有合法 PLC 形式。 |
| 任意複雜條件 | 缺少已確認的連接分支編碼時，仍拒絕需要自動 helpers 的設計。 |
| 全指令執行模擬 | 目前明確支援的子集以 simulation_model 為準；硬體、通訊、記憶匣、迴圈等不以虛構結果代替。 |
| WinProLadder GUI | 每一份檔案須以 hash 記錄匯入結果，不能由原始樣本截圖繼承。 |
| 實體 PLC | 需指定機型、韌體、時間基準與現場測試條件；本次未下載、啟停或驅動實體輸出。 |
