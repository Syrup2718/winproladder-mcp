# MCP v0.2：樣本 block、交叉引用與檔案差異

本版新增兩個 read-only MCP tools，工具總數為 11，並擴充既有 read/create/modify 流程。

## 新能力

- `read_ldr` 回傳人類可讀 description。所有 network 均可解碼時，額外回傳可直接交給
  `validate_ladder/create_ldr` 的 `ladder`；否則為 null，避免遺漏 unknown network。
- `analyze_ldr(path)` 回傳各 network 說明、元件 reads/writes 的 N 編號、multiple_writers。
  unknown network 不參與交叉引用，並回 `complete=false` 與 `opaque_networks`。
- `compare_ldr(left_path, right_path)` 以原始 record 對齊，比對顯示順序的 insert/delete/replace，
  不會因中間插入一個 network 就把全部後續內容視為改變。範圍採 `[start, end)`。
  payload、trailer 和 CRC 都參與比較。重複 network 的對齊可能不唯一，且不判定邏輯等價。
- inspect/read 回傳 SHA-256，方便核對版本。
- 可辨識並重建下表 8 種**完整已觀測 network**；這不是通用 Timer/Counter encoder。

## Block whitelist

| type | address | preset | coils | 證據 |
| --- | ---: | ---: | --- | --- |
| timer | 1 | 100 | Y4 | test N003 |
| timer | 2 | 101 | Y0 | test2 N004 |
| timer | 1 | 256 | 無 | test3 N004 |
| timer | 2 | 1000 | 無 | test3 N005 |
| timer | 3 | 101 | 無 | test3 N006 |
| counter | 1 | 10 | 無 | test3 N007 |
| counter | 2 | 16 | 無 | test3 N008 |
| counter | 3 | 17 | 無 | test3 N009 |

Timer time_base 固定 `0.01s`，enable 固定 `always_on`。
Counter pulse/clear 都固定 `always_on`，代表截圖的 PLS/CLR 接母線。
不得加入 steps、empty 或改動 coil 組合。清單以外參數回 UnsupportedInstruction；
即使 allow_unverified=true 也不會猜測 bytes。
`get_capabilities.block_templates` 提供完整 IR、raw payload 及來源 network。

所有 block 生成仍需 allow_unverified=true；原始匯出證據不等於重新生成檔案已匯入成功。
`validate_ladder.block_evidence` 回傳每個 network 的 evidence。
`simulate_ladder` 明確拒絕 Timer/Counter block，不以布林邏輯代替計時/計數。
T1/C1 普通接點仍可作固定初始值進行原有布林模擬。

## Agent 範例

> 分析 samples/test3.ldr，列出 Timer/Counter 和 C1、M2 的讀寫位置。

> 讀取 samples/test3.ldr，用回傳的 ladder 建立 artifacts/test3-rebuilt.ldr，
> 設 allow_unverified=true，然後比較兩個檔案是否逐 byte 相同。

注意工具 output_name 僅填 `test3-rebuilt.ldr`，不要填 `artifacts/` 路徑。

> 比較 samples/test3.ldr 與 artifacts/modified.ldr，列出新增、刪除和修改的 network。

## 驗證範圍

87 個 pytest 測試通過；ruff 與 mypy 通過。實際 MCP client 可探索 11 個工具，
完成 block 生成/讀取及預期錯誤回傳；自我檢查驗證原自保持檔案 SHA-256 保持不變。

逐個 block 與真實 sample 的 N 編號及 payload 比對；未知參數不外推；
test3 全部 12 networks 從 .ldr→IR→.ldr 逐 byte 一致；
test4 的 N002/N005/N006/N007 仍 opaque 且交叉引用明確不完整。
另外測試實際 MCP block 生成/讀取、模擬拒絕、插入對齊、反向刪除比對及 CRC-only 差異。

v0.1 的安裝流程不變：更新後 `uv sync --locked`、`uv run winproladder-setup check`，重啟 MCP 連線。
本版仍不支援一般巢狀分支、邊沿接點或 PLC 通訊。
