# MCP v0.1 交付狀態

## 已完成

- stdio MCP server、9 tools、capabilities resource 與 Pydantic JSON schema。
- 256-byte header / network record / CRC / footer 的結構 Parser/Encoder。
- 五個原始 `.ldr`（35 records）的逐 byte lossless round-trip。
- Unknown payload / trailer / tail 保留；修改其他 network 不會丟棄未知指令。
- 有限 contact/coil IR、驗證、布林 scan 模擬、create/export/replace/insert/delete。
- 自保持模板，生成結果與使用者成功匯入的 candidate 完全相同。
- 專案級 Codex 設定、其他 stdio client 設定範例、agent 使用指南。
- wheel / sdist 建置與隔離環境 console entry point 啟動檢查。

## 驗證結果

66 個 pytest 測試通過；ruff、mypy、git diff --check 通過。
端到端測試使用實際 stdio ClientSession，涵蓋全部 tools、resource、成功與失敗回傳。
`scripts/smoke_mcp.py` 使用 `.codex/config.toml` 的實際 command/args/cwd 啟動，
建立 `artifacts/start_stop_mcp.ldr`（281 bytes），與既有候選檔完全相同。
SHA-256：`b917c9e8d50f38f6d6b568637e3afd3f0ef6091ea49a8aaca6b1b4f73db025b9`。
smoke script 不覆蓋既有輸出；若要重跑，先保留舊檔並選擇新的輸出名稱。
現在支援 `uv run python scripts/smoke_mcp.py --output-name another.ldr`。
一般安裝驗證優先使用 `uv run winproladder-setup check`，在暫存目錄測試並清理，
可直接重跑。`config --format codex/json` 產生本機設定；實際設定不再納入 Git 或 sdist。

## 尚未支援

Timer/Counter block、edge contact、反相 coil、nested branch 的語意生成；
其他型號/版本或完整裝置位址範圍；WinProLadder 自動 syntax check；PLC 通訊/寫入。
這些內容可在已辨識 framing 下原樣保存，不會自動升級為可編碼能力。

目前交付為可供 agent 使用的有界 MCP v0.1，不是完整 WinProLadder 指令集。
現有 client 對話未必即時載入新增工具；重新載入 MCP 連線後使用 `get_capabilities` 確認。
